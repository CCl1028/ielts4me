# 统计仪表盘设计

## 概述
新增独立统计页面 `/stats`，展示学习数据与反馈，帮助用户了解整体进度、趋势变化和薄弱点。

## 技术方案
- 纯 CSS + Naive UI 组件，不引入额外图表库
- 新增 `StatsPage.vue`
- 导航栏新增"统计"入口

## 页面模块

### 1. 概览数字卡片（一行 4 个）
- 累计练习次数
- 练习天数（按日期去重）
- 平均正确率
- 已覆盖试卷数（X / 29）

### 2. 正确率趋势柱状图
- 最近 10-15 次练习
- 纯 CSS 柱状图，高度 = 正确率百分比
- 三档配色：≥80% 绿、≥60% 黄、<60% 红
- Tooltip 显示试卷名 + 正确率 + 日期
- 数据不足 3 次时显示鼓励文案

### 3. 练习热力格（类 GitHub 贡献图）
- 最近 8 周（56 天）
- CSS Grid 7行 x 8列
- 颜色深浅表示当天练习次数

### 4. 章节正确率对比
- 每章一行 n-progress 进度条
- 按正确率从低到高排列
- 未练习的章节灰色 + "未练习"标签

### 5. 高频错词 TOP 10
- 横向条形图（CSS 实现）
- 显示单词、错误次数、最近错误日期
- 色条颜色按错误次数分级

### 6. 最佳/最差成绩卡片
- 两张并排卡片
- 最佳：正确率最高的试卷
- 最差：正确率最低的试卷
