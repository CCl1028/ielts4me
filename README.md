# 雅思听力语料库听写练习

配合《雅思王听力真题语料库》使用的在线听写练习工具，帮助备考雅思听力的同学通过反复听写训练提升单词拼写准确率。

## 功能

### 听写练习
- 按章节和试卷选择练习内容（4 个章节，29 份试卷）
- 逐词输入，实时显示进度
- 支持撤回上一个输入、修改已输入的词
- 支持提前提交（未输满也可批改）

### 自动批改
- 提交后自动批改，逐题对比用户答案与正确答案
- 分数百分比展示，三档颜色区分（优秀/良好/需提升）
- 显示中文释义（如试卷数据包含）

### 历史记录
- 所有练习记录本地持久化保存
- 按时间倒序展示，可展开查看逐题详情
- 错词统计表格，支持排序和分页

### 学习统计仪表盘
- **概览卡片**：累计练习次数、练习天数、平均正确率、已覆盖试卷数
- **正确率趋势**：最近 15 次练习的柱状图，直观看到进步
- **练习热力图**：最近 24 周的练习频次，类似 GitHub 贡献图
- **章节正确率对比**：各章节进度条排列，一眼定位薄弱章节
- **高频错词 TOP 10**：横向条形图展示最常出错的词
- **最佳/最差成绩**：最高分和最低分试卷对比


## 本地运行

### 第一步：安装 Node.js

1. 打开 [Node.js 官网](https://nodejs.org/zh-cn)
2. 下载 **LTS（长期支持版）**，版本号需 >= 18
3. 双击下载的安装包，一路点"下一步/继续"完成安装
4. 验证安装成功：打开终端（Mac 搜索"终端"，Windows 搜索"命令提示符"或"PowerShell"），输入：
   ```bash
   node -v
   ```
   如果显示类似 `v20.x.x` 的版本号，说明安装成功

### 第二步：下载项目代码

将收到的项目压缩包（.zip）解压到电脑上任意位置即可，例如桌面或文档文件夹。

### 第三步：安装项目依赖

1. 打开终端
2. 进入项目文件夹（把路径替换为你实际解压/克隆的位置）：
   ```bash
   cd /你的路径/ielts4me
   ```
   > 提示：Mac 可以输入 `cd ` 后把文件夹拖进终端窗口，会自动填入路径
3. 执行安装命令：
   ```bash
   npm install
   ```
   等待安装完成（可能需要 1-2 分钟，期间会有进度输出）

### 第四步：启动项目

在同一个终端窗口中执行：
```bash
npm run dev
```

启动成功后终端会显示类似以下内容：
```
VITE v5.x.x  ready in xxx ms

➜  Local:   http://localhost:5173/
```

### 第五步：打开页面

在浏览器（推荐 Chrome）地址栏输入终端中显示的地址（通常是 `http://localhost:5173`），回车即可使用。

### 如何停止

在终端按 `Ctrl + C` 即可停止服务。下次使用时重复第四、五步即可（不需要重新安装）。

### 其他命令

```bash
# 生产构建（生成可部署的静态文件到 dist/ 目录）
npm run build

# 预览构建产物
npm run preview
```
